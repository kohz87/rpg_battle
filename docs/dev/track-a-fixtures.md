Quest fixtures exercise real SB/SD/RB definitions on the enforcing host. They cover retained
selectors/aliases, P23 retry/atomicity, neutral-to-RPG linking, legacy unpaid history, fresh
repeat/chain IDs, rollback, swipe/delete/Re-read/reload, Continue, deadline equality, caller
authority, closed prerequisites and story-coin deduplication. Pure planners cover owner refusal
and missing B3 validators. Equipment fixtures cover pure eight-slot plans and SB hash parity.

Host fixtures explicitly supply D1 cursor()/epoch. They import B's buildGuard from this
checkout when integrated; otherwise they skip with a reason. For an independent B checkout:

```sh
RPG_BATTLE_PROGRESS_DIR=/path/to/B/src/v2/progress npm run test:dot
```

Missing sibling SD also skips these integration fixtures. Neither loader copies source nor
requires branch git objects. Single-repo copies pass without siblings or a .git directory.
Full counts and remaining integration work are in track-a.md.
